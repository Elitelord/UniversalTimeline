# UniversalTimeline
Universal Activity Timeline is a cross-platform activity tracking system that aggregates your digital activity from Windows and Android into a single, searchable chronological timeline. Platform clients monitor foreground applications, browser activity, and idle state, then sync event data in offline-tolerant batches to a centralized NestJS backend powered by PostgreSQL and TimescaleDB. A Next.js frontend renders your day as a color-coded timeline with daily summaries, search, and filtering. Built with TypeScript end-to-end, containerized with Docker, and authenticated via Supabase Auth.
